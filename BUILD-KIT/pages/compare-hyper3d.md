# How does Hydrilla compare to Hyper3D?

Hydrilla AI and Hyper3D build separate 3D models. Hydrilla uses BlueFox, Hydrilla's 3D model, and Hyper3D runs Rodin. Both accept text or images; their exports, plugins, and plans differ.

**[Section 2: Table]**

## Side by side

| | Hydrilla | Hyper3D (confirm on hyper3d.ai) |
|---|---|---|
| Model | [BlueFox 1 →](/bluefox) | Rodin; its site names Gen-2.5 |
| Inputs | Text, or a reference image | Image, text, and multi-image |
| Result | Segmented mesh carrying PBR maps | Textured mesh, with parts and low-poly options listed |
| Exports | Four formats, listed on [exports →](/features#exports) | STL, FBX, OBJ, GLB, glTF, and USDZ, per its FAQ |
| Plugins | Plugins for four tools, through a [local Bridge →](/integrations) | Blender, Unity, Unreal, Godot, Maya, 3ds Max, and ComfyUI |
| API and MCP | REST jobs and an MCP server, see [API →](/api) | API and MCP, both listed in its navigation |
| Plans | Credits, a Free plan, and a published cost per model | Free, Creator, Business, and Enterprise tiers |
| Team features | Seats and API concurrency through Enterprise | Multi-team management, shared workspace, and compliance, per its homepage |
| AI 3D agent | [Water Agent →](/water) builds and revises whole asset sets in conversation, on every plan, no credits | Confirm on hyper3d.ai |

**[Section 3: Fit]**

## When each one fits

Hydrilla fits studios that want a documented flagship model, an agent that works through whole sets with your artists, and a local Bridge into their existing scene tools. Hyper3D fits teams that need printing formats, ComfyUI, or Maya and 3ds Max plugins today.

## Check before you decide

Rodin's tiers, formats, and plugins can change. Confirm each row on [hyper3d.ai →](https://hyper3d.ai) first.
