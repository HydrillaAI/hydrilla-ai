# How does Hydrilla compare to Sloyd?

Hydrilla AI and Sloyd approach 3D creation differently. Hydrilla runs BlueFox, Hydrilla's 3D model, to generate segmented 3D meshes with PBR maps from open prompts or reference images, while Sloyd combines a parametric template editor with text and image generation.

**[Section 2: Table]**

## Side by side

| | Hydrilla | Sloyd (confirm on sloyd.ai) |
|---|---|---|
| Approach | Open-domain generation with [BlueFox 1 →](/bluefox) | Parametric template generator plus text, image, and 3D-to-3D tools |
| Inputs | A text prompt or one reference image | Sliders on parametric templates, text prompts, or an image |
| Output | Segmented mesh with UVs and PBR maps | Low-poly template meshes or generated textured meshes |
| Export formats | Four formats ([list →](/features#exports)) | GLB, OBJ, FBX, and STL, per its site |
| Engine and DCC tools | Four plugins linked by a local Bridge ([integrations →](/integrations)) | Blender, Unity, Unreal, and Roblox plugins listed on its site |
| API and agents | Job-based REST API and an MCP server ([API →](/api)) | Real-time template SDK and generation API |
| Pricing model | Monthly credit plans with a Free tier and Hourly plans ([pricing →](/pricing)) | Free tier plus Plus, Studio, and Enterprise subscription plans |
| Model card | Published on [research →](/research#model-card), with intended use and limits | Confirm on sloyd.ai |
| AI 3D agent | [Water Agent →](/water) builds and revises whole asset sets in conversation, on every plan, no credits | Confirm on sloyd.ai |

**[Section 3: Fit]**

## When each one fits

Hydrilla suits studios and artists who start from custom reference photos, concept art, or scene briefs, and want segmented meshes with PBR maps plus Water Agent to direct whole sets inside their tools. Sloyd suits teams that want slider-driven variations on categories covered by its template library or need STL exports for printing.

## Check before you decide

Sloyd's template library, generated modes, and plans change over time. Confirm each row on [sloyd.ai →](https://www.sloyd.ai) before you commit, then test both tools using the [buying guide →](/compare/how-to-choose).
